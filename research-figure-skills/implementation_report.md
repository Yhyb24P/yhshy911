# Research Figure Skills V1 Implementation Report

## Status

COMPLETE

## Implemented

Three executable skills: evidence-constrained quantitative rendering, semantic-graph-to-editable-SVG rendering, and independent PDF/SVG/PNG preflight. The implementation provides strict JSON schemas, SHA-256 provenance, Nature physical sizing (90/180 mm), 450-DPI PNG export, vector PDF/SVG export, semantic evidence checks, and pytest coverage.

## Directory

`nature-figure/`, `scientific-schematic/`, `figure-preflight/`, `shared/`, `schemas/`, `examples/`, and `tests/` are contained in this directory.

## Known limitations

V1 is deliberately local-only and provides deterministic rendering rather than automated scientific interpretation. Preflight reports manual-review items for causal, biological, and mechanism validity. Structural biology must be generated by a real structure tool (for example PyMOL or ChimeraX), not this renderer.

## Manual checks

Review the declared scientific claim, evidence quality, interpretation, statistical appropriateness, and journal-specific composition before submission.
