# Scientific Schematic
Every semantic node and edge must cite explicit evidence. Never invent pathways, interactions, causation, dependencies, or data flow; never convert correlation into causation. Workflow: evidence → semantic graph → schema/semantic validation → deterministic layout → editable SVG → evidence audit.
