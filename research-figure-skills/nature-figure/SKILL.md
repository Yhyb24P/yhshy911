# Nature Figure
Use only real data, explicit numerical data, or reproducible analysis output. Never invent data, p-values, error bars, sample sizes, conditions, labels, or causal claims. Missing evidence is `FAIL_CLOSED`.

Workflow: validate source and units, create/validate `figure_spec.yaml`, render at final physical size, export PDF/SVG/PNG, write provenance, and run preflight. Use for quantitative figures, not mechanisms or free-form illustration.
